Codai Player 자막 플레이어

내 폰과 PC에 있는 영상에 자동으로 자막을 붙여 주는 플레이어. 영상은 어디에도 올라가지 않습니다.

안드로이드 APK 받기 (준비 중) 윈도우 앱 받기

최신 버전 - · 초대 코드가 있어야 서버에 연결할 수 있어요.

무엇을 하나요

  • 폰이나 PC에 있는 영상을 재생하면서 자막을 보여 줍니다.
  • 같은 영상의 자막을 누가 이미 만들어 두었으면 바로 받아 옵니다.
  • 없으면 영상의 소리만 서버에 보내 음성 인식과 번역으로 자막을 만듭니다. 보고 있는 자리부터 먼저 만들어져 1~2분 안에 자막이 나타나기 시작합니다.
  • 만든 자막은 같은 영상을 가진 다른 사용자에게 공유됩니다.

보내지 않는 것

  • 영상 파일. 서버로 가는 것은 파일 해시, 소리, 자막 텍스트뿐입니다.
  • 보낸 소리는 자막을 만든 뒤 바로 지웁니다.

설치

안드로이드: APK를 받아 열면 "알 수 없는 앱 설치"를 허용해 달라고 합니다. 허용 후 설치하세요. 업데이트도 같은 방법입니다.

윈도우: 파일 하나(CodaiPlayer-버전.exe)를 받아 실행합니다(설치 없음, 첫 실행은 몇 초 걸립니다). SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요(서명 인증서가 없어서 뜹니다). 영상 파일을 exe에 끌어다 놓아도 열립니다.

연결: 첫 실행에서 서버 주소와 초대 코드를 넣고 아이디를 만듭니다. 초대 코드는 운영자에게 받으세요.

후원

서버 한 대와 GPU 한 장으로 돌아갑니다. 전기세와 서버 유지에 보태 주시면 감사합니다. 후원은 자발적이고, 후원 여부와 상관없이 같은 기능을 씁니다.
